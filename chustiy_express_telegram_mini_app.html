Telegram Bot Ishga Tushirish Kodingiz

Aiogram 3.x (Python) orqali WebApp ulash

ℹ️ Nega to'g'ridan-to'g'ri Telegram bot nomi berilmadi?

Telegram bot doimiy 24/7 ishlashi uchun tashqi serverda (VPS/Cloud) o'z API tokeni bilan yoniq turishi shart. Sun'iy intellekt sifatida menda tashqi serverda bepul shaxsiy Telegram bot ro'yxatdan o'tkazish imkoni yo'q (mavjud bo'lmagan bot nomini yozib yolg'on gapirmayman). Buning o'rniga sizga tayyor Mini App saytini va uni o'z botingizga 2 daqiqada ulash kodini berdim!

1-qadam: Bot yaratish (@BotFather)

  1. Telegram'da @BotFather ni oching va /newbot yozing.
  2. Botga nom va username bering (masalan: mening_oshxonam_bot).
  3. BotFather bergan BOT_TOKEN ni nusxalang.

2-qadam: Python kodi (bot.py)

import asyncio
from aiogram import Bot, Dispatcher, types
from aiogram.filters import CommandStart
from aiogram.types import InlineKeyboardButton, InlineKeyboardMarkup, WebAppInfo

# BotFather bergan tokenni bu yerga qo'ying
TOKEN = "SIZNING_BOT_TOKENINGIZ"
# Sayt havolasi (GitHub Pages, Vercel yoki ushbu WebApp)
WEBAPP_URL = "https://example.com/miniapp.html"

bot = Bot(token=TOKEN)
dp = Dispatcher()

@dp.message(CommandStart())
async def start_handler(message: types.Message):
    kb = InlineKeyboardMarkup(
        inline_keyboard=[[
            InlineKeyboardButton(
                text="🥟 Chustiy Express (Mini App)",
                web_app=WebAppInfo(url=WEBAPP_URL)
            )
        ]]
    )
    await message.answer(
        f"Assalomu alaykum, {message.from_user.full_name}!
"
        "Chustiy Express milliy taomlar do'koniga xush kelibsiz.
"
        "Pastdagi tugmani bosib taomlarni tanlang:",
        reply_markup=kb
    )

async def main():
    print("Bot ishga tushdi...")
    await dp.start_polling(bot)

if __name__ == "__main__":
    asyncio.run(main())
